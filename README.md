# Few Foodies

A modern landing page for "Few Foodies" - a vibrant community platform for food enthusiasts.

## Project Overview

This is a responsive single-page website showcasing the Few Foodies platform with features including:

- **Navigation Bar** - Links to key sections and sign-in button
- **Hero Section** - Eye-catching introduction with featured category
- **Features Grid** - Showcase of 8 key platform features
- **Call-to-Action Section** - Conversion-focused signup prompt

## Features

- 🍽️ What's in My Fridge? - AI-powered recipe generator
- 👥 Cooking & Groups - Guides and collaborative spaces
- ✅ The Daily Bite - Member-only polls & challenges
- 🎫 Foodie Rewards - Exclusive local deals
- 🎙️ Podcast - Listen to foodie stories
- 📅 Meetups & Events - Join local gatherings
- ✏️ Create Content - Share your culinary journey
- ✈️ Travel - Foodie destinations

## Getting Started

1. Open `index.html` in your web browser
2. The site is fully responsive and works on mobile, tablet, and desktop

## Technical Stack

- **HTML5** - Semantic markup
- **CSS3** - Responsive design with CSS Grid and Flexbox
- **JavaScript** - Smooth scrolling and scroll animations

## Responsive Design

The website is fully responsive with breakpoints at 768px for mobile optimization.

## Browser Support

Works on all modern browsers that support:
- CSS Grid and Flexbox
- CSS3 animations
- ES6 JavaScript (IntersectionObserver API)
